# 🍽️ Restaurant QR System

A modern full-stack restaurant ordering system where customers can scan a QR code placed on a restaurant table, browse the digital menu, place orders, and receive real-time order updates.

## ✨ Features

### Customer
- Scan QR code
- Browse menu
- Add items to cart
- Place orders
- Add special instructions
- Track order status

### Kitchen
- Receive new orders instantly
- Update order status
- Real-time order notifications

### Admin
- Manage menu
- Manage tables
- Generate QR codes
- View orders
- Analytics (Coming Soon)
